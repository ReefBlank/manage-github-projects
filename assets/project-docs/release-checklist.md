# 发布检查清单

> 只有全部阻塞项清零后才可执行发布。每项都要标注证据等级。

## 门禁

- [ ] 「发布方案确认」已由用户明确回复
- [ ] 版本号一致性检查通过（tag / package.json / CHANGELOG / Release 标题）

## 内容与合规

- [ ] README.md 能让陌生人回答：这是什么、怎么装、怎么用、怎么贡献
- [ ] LICENSE 与用户选定类型一致
- [ ] CHANGELOG 顶部条目与实际变更一致，未编造功能
- [ ] 社区文件齐备（CONTRIBUTING / CODE_OF_CONDUCT / SECURITY）
- [ ] CI 工作流结论为通过

## 安全

- [ ] 敏感信息扫描无命中
- [ ] 工作区干净，无未提交改动混入发布
- [ ] 危险操作已安全跳过，或已取得单项授权并记录

## 版本与发布物

- [ ] tag 使用带注解 tag 并已推送
- [ ] GitHub Release 已创建，预发布版本已勾选 pre-release
- [ ] Release 说明来自实际变更
- [ ] Release 附件可下载

## 证据等级汇总

| 结论 | 证据等级 |
| --- | --- |
| 本地状态 | L2 本地 Git |
| 远程状态 | L3 远程 API |
| CI | L4 CI |
| 发布物 | L5 发布物 |

## 发布后

- [ ] 记录发布时间与版本号到 progress.md
- [ ] 更新 decisions.md 中的发布节奏决策
- [ ] 规划下一个版本
